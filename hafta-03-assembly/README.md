# Hafta 3 — Assembly ve Mate'ler (Gün 15–21)

**Bitiş görevi:** Çalışan bir dört çubuk mekanizması kurmak (hareket eden, kilitlenmemiş).

## Kaynaklar
- Dahili: `Temel Teknikler > Montajlar`
- MySolidWorks ücretsiz patikalar: *Basic Assembly Modeling*, *Assemblies: Mates*
- `Üretkenlik Araçları`: Configurations, Design Tables, Equations ← gripper varyantları için birebir

## Oturması gerekenler
- Standard mate: Coincident, Concentric, Parallel, Distance, Angle
- Advanced mate: Width, Limit, Path
- Mechanical mate: Gear, Hinge, Cam, Screw
- **Serbestlik derecesi (DOF):** Bir parçanın kaç serbestliği kaldığını okumak. Fazla mate = over-constrained = hareketsiz mekanizma
- Fix / Float, alt-montaj (subassembly) mantığı
- `Move Component > Physical Dynamics` ile mekanizmayı elle test etmek

## Not
Dört çubuk mekanizması, gripper kavrama kinematiğinin temeli. Buradaki DOF sayımı 5. haftada doğrudan kullanılacak.

# Hafta 1 — Sketch Disiplini (Gün 1–7)

**Bitiş görevi:** Orta zorlukta bir sketch'i 10 dakikada, rehbersiz, Fully Defined çizmek.

## Öğretici sırası
Kaynak: `Yardım > SOLIDWORKS Öğreticileri` (dahili, çevrimdışı)

- [x] SOLIDWORKS'e Giriş → [Gün 1: pressure_plate](g01-pressure-plate/)
- [ ] AutoCAD ve SOLIDWORKS ← AutoCAD geçmişi için kritik
- [ ] Ders 1: Parçalar
- [ ] Ders 3: Teknik Resimler
- [ ] Ders 2: Montajlar

## Bu hafta oturması gerekenler

- **İlişkiler (relations):** Coincident, Collinear, Parallel, Perpendicular, Tangent, Concentric, Equal, Symmetric, Fix
- **Fully Defined / Under Defined / Over Defined** farkı ve durum çubuğundan okunması
- Ölçü mü ilişki mi? → Kural: **önce ilişki, sonra ölçü.** Ölçüyle zorlamak tembelliktir, model sonra kırılır.
- Origin'e bağlanma alışkanlığı — her sketch bir referansa oturmalı
- Construction geometry (yardımcı çizgi) kullanımı
- Sketch çözümleme: `Display/Delete Relations`, `View > Sketch Relations`

## AutoCAD'den gelenler için tuzaklar

| AutoCAD alışkanlığı | SolidWorks'te sorun |
|---|---|
| Her şeyi tam koordinatla çizmek | Parametrik olmaz; sonradan değişmez |
| Ölçü = tek doğruluk kaynağı | Burada ilişkiler ölçüden önce gelir |
| Çizip bırakmak | Fully Defined olmayan sketch = yarım iş |
| Layer mantığı | Yok; yerine feature ağacı var |

## Dosyalar

# SolidWorks Öğrenme Süreci

Dicle Üniversitesi Makine Mühendisliği 3. sınıf öğrencisiyim. Bu repo, 16 Ağustos 2026'da sıfırdan başladığım SolidWorks öğrenimimin günlük kaydıdır.

**Neden var:** Öğrenmeyi görünür kılmak, takıldığım yerleri arşivlemek ve tempoyu ölçülebilir tutmak için. Nihai amaç SolidWorks'ü "bitirmek" değil; MTA Lab'deki UFACTORY xArm 5 robot kolu için adaptif bir gripper tasarlayıp Bambu P2S'te basabilecek seviyeye gelmek.

## İki kural

1. **Altın kural:** Bir sketch, "Fully Defined" yazana kadar bitmiş sayılmaz.
2. **Takılma kuralı:** Bir şeyde 20 dakikadan fazla takılırsam bırakıp not alıyorum, ertesi güne geçiyorum.

# Tolerans Test Kuponu

## Amaç
Bambu P2S + kullanılan filament + kullanılan dilimleme ayarları kombinasyonu için gerçek geçme boşluklarını deneysel belirlemek.

## Tasarım (taslak)
Tek plakada, tek referans pim + artan çaplarda delik dizisi.
- Nominal pim çapı: 8,00 mm
- Delik çapları: 8,00 / 8,10 / 8,20 / 8,30 / 8,40 / 8,50 / 8,60 mm
- Her deliğin yanında kabartma etiket
- Test hem X-Y düzleminde hem Z ekseninde tekrarlanır (anizotropi kontrolü)

# Hafta 4 — 3D Baskı İçin Tasarım (DfAM) (Gün 22–28)

Kurallar → [../notlar/dfam-kurallari.md](../notlar/dfam-kurallari.md)

## Tolerans testi
`tolerans-testi/` klasöründe:
- Test kuponu modeli (delik/pim çiftleri, artan boşluklarla)
- Baskı ayarları (nozzle, katman yüksekliği, duvar sayısı, dolgu)
- Ölçüm sonuçları tablosu
- Sonuç: kendi makinem için geçme boşluğu değerleri

## Neden kendi değerlerim?
ISO 286 (H7/g6 vb.) geçme sistemi talaşlı imalat hassasiyeti varsayar; FDM'de doğrudan uygulanamaz. Literatürdeki değerler başlangıç noktası, gerçek değer deneyle bulunur.
